# DivTracker

DivTracker 是一個專為台股投資人設計的除權息追蹤工具。透過整合即時股價資料與用戶個人持股紀錄，協助您輕鬆管理投資組合，掌握每一筆股利分配。

## 主要功能

*   **個人投資組合管理**：建立並維護您的台股清單，即時同步持股張數與現價。
*   **除權息資訊追蹤**：自動抓取最新的除權息日期、配息金額與發放日。
*   **股利發放試算**：根據歷史持股狀況與除權息日期，精確計算預期領息金額。
*   **歷年報表紀錄**：自動產生歷年領息報表，清楚呈現投資收益趨勢。
*   **狀態管理**：提供「持股中」與「已清倉」分類檢視，並妥善保留已清倉股票的歷史數據。
*   **自動化排程**：每日自動更新股價並產生個人投資組合快照，確保數據準確。

## 技術棧

*   **前端**：React, TypeScript, Tailwind CSS, Framer Motion
*   **後端**：Node.js, Express
*   **資料庫**：Google Firebase (Firestore)
*   **部署**：Google Cloud Run
